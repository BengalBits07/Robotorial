# Bengal Bits | Robotorial Platform

A modern, fluid, and animated robotics landing page for **Bengal Bits** and their flagship robotics and automation club, **Robotorial**, strictly powered by live data sourced from [bengalbits.com](https://www.bengalbits.com/).

---

## 🌟 Content & Branding Updates

### 1. Primary Bengal Bits Logo
- **Uploaded Image Integration**: Strictly utilizes the uploaded image (`assets/bengalbits-logo.webp`) as the primary brand logo in the navigation bar.
- **Header Alignment & Sizing**: Sized appropriately (`h-11`, max-width `180px`, object-contain) with a subtle border and shadow, properly aligned to the left, and linking directly back to the Home (`#hero`) section.

---

### 2. The 'Robotorial' Section (Core Robotics & Automation Hub)
- Framed explicitly as the **hands-on hardware, robotics, and automation training arm of Bengal Bits**.
- Exclusively populated with:
  - **Obstacle Avoidance Car**: Autonomous 4WD rover scanning hemisphere clearance via sonar radar.
  - **Smart Dustbin**: Ultrasonic proximity actuation & fill telemetry device.
  - **Human Following Car**: Real-time human tracking with dynamic distance heading control.
  - **Sensor Integration Details**: Multi-probe telemetry module covering Ultrasonic HC-SR04, MPU-6050 6-DOF IMUs, optical IR, capacitive moisture probes, and analog calibration.
- Interactive model selector and technical spec matrix (Dimensions, Philosophy, Color, Illumination, and Appearance).
